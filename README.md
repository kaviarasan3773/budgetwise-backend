# BudgetWise Backend

Backend application for the BudgetWise personal finance management system.

## Project Description

BudgetWise is a personal finance management application designed to help users manage and track their financial activities such as income, expenses, and investments.

This repository contains the backend implementation of the application.

## Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* MySQL
* Maven
* REST APIs

## Features

* User Registration and Login
* User Profile Management
* Income Management
* Expense Management
* Investment Management
* Financial Reports

## Project Structure

The project follows a layered backend architecture:

* Controller – Handles REST API requests
* Service – Contains business logic
* Repository – Handles database operations
* Entity – Represents database entities

## Database

MySQL is used as the relational database for storing application data.
